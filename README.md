# Lin Local

## How do I install these formulae?

`brew install lin/local/<formula>`

Or `brew tap lin/local` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "lin/local"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
